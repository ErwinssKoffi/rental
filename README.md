# 🚗 Car Rental Platform

A modern and responsive car rental platform built with Next.js.

## 🌐 Live Demo

https://[car-liard-five.vercel.app](https://car-7its.vercel.app/)

## ✨ Features

- Browse available cars
- Car details page
- Search and filtering
- Responsive design
- Modern UI/UX
- Fast performance

## 🛠️ Tech Stack

- Next.js
- React
- JavaScript
- Tailwind CSS

## 🚀 Getting Started

```bash
npm install
npm run dev
```

```
app/
components/

public/
```
